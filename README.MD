
# Star Fox EX
Source tree for Star Fox EX.  
  
For older source revisions and builds, see [here](https://archive.org/details/Starfox-EX-Archive).  

As of November 8, 2026, this repository has been placed into archive mode and is read-only.  
Star Fox EX 1.11.03 will be the final update. Any remaining bugs and issues will not be fixed.  
The new arrangements of the Star Fox EX soundtrack contained in this repository intended for the MSU-1 version were composed by Random and cannot be reused without their permission.
